# Contributing

Thanks for your interest in contributing to Multi-Route Launcher for Claude Code.

## Before submitting changes

Please make sure that:

- No API keys, tokens, cookies, sessions, passwords, or private credentials are included.
- No personal server addresses or private project paths are committed.
- User-specific files such as profiles, launcher-state.json, projects.json, settings.json, and *.secret files are not committed.
- Changes remain compatible with Windows PowerShell 5.1 where applicable.
- Existing launcher behavior is not silently broken.

## Pull Requests

Please keep pull requests focused on one clear change.

Describe:

- What was changed
- Why it was changed
- How it was tested
- Any compatibility or security impact

## Security

Do not open a public issue containing real credentials or private account information.

For security-related guidance, see SECURITY.md.

## Project status

This is an independent third-party launcher and is not affiliated with or endorsed by Anthropic.
