Claude Multi-Route Launcher - Public Edition 1.0.2

Status: Windows end-to-end validation PASS

Validated flow:
1. Launch on a clean folder.
2. First-run wizard.
3. Detect installed Claude Code.
4. Use a user-scoped default project directory.
5. Import a New API connection JSON.
6. Retrieve model list.
7. Perform a live model availability test.
8. Launch Claude Code in the selected project.
9. Receive a real model response.

Security / privacy:
- No bundled API key.
- No bundled OAuth/session/cookie.
- No user-specific API route.
- No fixed D: drive dependency.
- User API secrets remain Windows-user encrypted in local app data.
- This is an independent third-party launcher, not an Anthropic product.
